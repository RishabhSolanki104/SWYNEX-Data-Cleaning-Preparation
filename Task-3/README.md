# 📊 Employee Analytics Dashboard | Power BI

An interactive **Employee Analytics Dashboard** built using Microsoft Power BI to analyze employee distribution, salary patterns, and hiring trends.

## 📌 Project Overview

This project transforms employee data into an interactive dashboard that provides insights into workforce distribution, salary ranges, departmental salary comparisons, and employee hiring trends.

The dashboard allows users to explore the data using interactive **Department** and **Year** filters.

## 📊 Key Metrics

- 👥 Total Employees: 470
- 💰 Total Salary: 49M
- 📈 Average Salary: 103.64K

## 🔍 What I Analyzed

- Employee distribution across departments
- Salary distribution across different salary ranges
- Average salary by department
- Employee hiring trends over the years
- Minimum and maximum salary by department
- Department and Year-wise analysis using slicers

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Data Modeling
- Data Visualization
- Data Analysis

## 📈 Dashboard Components

The dashboard includes:

- Employee Distribution by Department
- Employee Salary Distribution
- Employee Hiring Trend
- Average Salary by Department
- Department-wise Salary Summary Table
- Interactive Department & Year Slicers
- Summary Cards for key metrics

## 🎯 Project Objective

The main objective of this project is to convert raw employee data into an **interactive and easy-to-understand analytical dashboard** that can support workforce and salary-related analysis.
