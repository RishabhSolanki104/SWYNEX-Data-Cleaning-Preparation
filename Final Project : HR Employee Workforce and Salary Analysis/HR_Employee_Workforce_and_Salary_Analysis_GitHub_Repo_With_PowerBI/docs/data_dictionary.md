# Data Dictionary

## Public Analytical Dataset

The public repository excludes employee names and email addresses to avoid exposing personal information.

| Column | Description | Type |
|---|---|---|
| Emp_ID | Employee identifier | Integer |
| Age | Employee age | Numeric |
| Join_Date | Employee joining date | Date |
| Department | Standardized department | Categorical |
| Salary | Employee salary | Numeric |

## Department Categories

- Sales
- Operations
- Finance
- IT
- Marketing
- HR
- Other
